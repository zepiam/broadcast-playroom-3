# เครื่องมือตรวจ Broadcast Playroom 3

ดับเบิลคลิก `open_checklist.bat` หรือเปิด `index.html` ด้วยเบราว์เซอร์ เครื่องมือทำงานในเครื่องโดยไม่ต้องเปิดตัวโปรแกรมหรือใช้อินเทอร์เน็ต

1. เลือกรุ่นและกรอกสภาพแวดล้อมที่ใช้ทดสอบตามต้องการ หากผล Lite และ Full ต่างกัน ให้บันทึกแยกเป็นคนละไฟล์เพื่อไม่ให้ผลปนกัน
2. เปิดแต่ละหมวด เลือก **ใช้ได้**, **ใช้ไม่ได้**, **ข้าม** หรือปล่อย **ยังไม่ตรวจ** พร้อมใส่รายละเอียดเพิ่มเติมถ้าต้องการ ใช้ช่องค้นหาและตัวกรองช่วยไล่รายการ
3. เพิ่มรายการที่ยังไม่มีได้ด้วยช่อง “เพิ่มรายการที่ยังไม่มีในแบบตรวจ” และเขียนภาพรวม/ลำดับงานในช่องสรุป
4. กด **บันทึกไฟล์ JSON** หลังตรวจแต่ละครั้ง แล้วส่งไฟล์นั้นให้ AI อ่าน รายงาน `.md` เป็นทางเลือกสำหรับอ่านง่าย แต่ JSON ใช้เปิดกลับมาตรวจต่อได้
5. เมื่อตรวจรอบถัดไป กด **เปิดไฟล์ JSON เดิม** ข้อมูลในไฟล์จะแทนที่ข้อมูลปัจจุบันหลังยืนยัน ควรบันทึกไฟล์ปัจจุบันก่อน

ข้อมูลบันทึกอัตโนมัติในเบราว์เซอร์และเครื่องที่ใช้งานเท่านั้น อาจหายหากล้างข้อมูลเบราว์เซอร์ เปลี่ยนเบราว์เซอร์ หรือย้ายเครื่อง จึงควรเก็บไฟล์ JSON ทุกครั้ง เครื่องมือนี้ไม่ได้ส่งไฟล์หรือข้อความออกไปเอง

รายการเริ่มต้นได้จากปุ่ม/ช่องใน `src/index.html` ร่วมกับรายการตรวจพฤติกรรมตามขอบเขตที่ตกลงไว้ ยังมีโอกาสขาดตัวเลือกที่โปรแกรมสร้างแบบไดนามิกหรือเปลี่ยนภายหลัง ให้ใช้ช่องเพิ่มรายการเอง ไม่ตีความรายการในแบบตรวจว่าเป็นผลรับรองว่าฟีเจอร์ใช้งานได้ เมื่อโปรแกรมเปลี่ยน ผู้พัฒนาสร้างรายการใหม่ด้วย `python quality_checklist/generate_catalog.py` โดยต้องมี BeautifulSoup (ตัวเครื่องมือที่เปิดใช้ไม่ต้องติดตั้ง Python)
