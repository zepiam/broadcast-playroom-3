วิธีใช้งานปลั๊กอิน (Plugin Starter Template):
=============================================
1. คัดลอกโฟลเดอร์นี้ แล้วเปลี่ยนชื่อโฟลเดอร์เป็นชื่อปลั๊กอินของคุณ (ห้ามขึ้นต้นด้วย _)
2. แก้ไขไฟล์ plugin.json เพื่อกำหนดชื่อและ ID ของปลั๊กอิน
3. นำโค้ดการทำงานใส่ใน main.py หรือแก้ไขหน้าจอตั้งค่าใน settings.html
4. คุณสามารถนำเอกสารใน docs/AI_PLUGIN_GUIDE.md ไปให้ AI (เช่น Gemini, Claude, ChatGPT) ช่วยเขียนโค้ดต่อได้ทันที!
