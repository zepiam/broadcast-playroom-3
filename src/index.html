รหัสผ่านที่บันทึกจะเข้ารหัสไว้ในบัญชี Windows เครื่องนี้ เว้นช่องรหัสผ่านว่างเพื่อใช้รหัสที่บันทึกไว้

เชื่อมต่อ OBS อัตโนมัติเมื่อเปิดโปรแกรม

⚡ Docks & Web URL สำหรับ OBS Studio
ลิงก์สำหรับนำไปใส่ในเมนู Docks -> Custom Browser Docks ของ OBS Studio
🖥️ 1. โอเวอร์เลย์รวมบนจอ (OBS Browser Source)
ความละเอียด 1920×1080 พิกเซล พื้นหลังโปร่งใส ซิงค์ทุกวิดเจ็ตอัตโนมัติ
🎛️ 2. แผงควบคุมสดใน OBS (OBS Custom Browser Dock)
นำไปใส่ในเมนู Docks -> Custom Browser Docks ของ OBS Studio
🌐 ระบบ Network & Custom DNS สำหรับ TTS Server
ตั้งค่า DNS สำหรับการเชื่อมต่อระบบอ่านเสียงของโปรแกรม โดยไม่เปลี่ยน DNS ของ Windows
⚡ บริการ DNS พิเศษ (DNS-over-HTTPS) ● ยังไม่ได้เปิดใช้
เปิดใช้งานระบบ Custom DNS
บังคับให้โปรแกรมส่งคำขอผ่านช่องทาง DNS พิเศษ ป้องกันปัญหาเสียงอ่านแชทสะดุดหรือหลุดการเชื่อมต่อ
📡 ทดสอบ DNS และบริการเสียง
ยังไม่ได้ทดสอบ
